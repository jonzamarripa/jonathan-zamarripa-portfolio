# Jonathan Zamarripa — Learning Experience Designer

**Portfolio website** showcasing strategic learning design, creative production, AI-enabled workflows, and enterprise transformation.

## About

I design clarity within complex systems. This portfolio documents four case studies spanning enterprise learning, product onboarding, sales enablement, and organizational change.

## Projects

### 1. Operation: Legacy Unlocked
**Learning Transformation at Scale**

Rebuilt a legacy training system for 8,000+ employees across a global organization. Introduced modern learning frameworks, AI-assisted content production, and measurable outcomes.

**Case Study:** How I transformed a fragmented training landscape into a cohesive learning ecosystem.

### 2. HotelKey New Hire Onboarding
**Mobile-First Training Experience**

Designed a mobile onboarding experience for hotel staff, enabling self-paced training in the workflow without classroom time.

**Case Study:** How mobile-first design and minimal friction create better outcomes.

### 3. Guest CRM Pilot
**Product Launch Acceleration**

Enabled rapid adoption of a new CRM system by building an in-product learning experience that lived inside the actual workflow.

**Case Study:** How embedded guidance outperforms traditional training.

### 4. Workday Learn Launch
**LMS Implementation & Change Enablement**

Architected learning strategy and content for a Workday implementation reaching 5,000+ users across multiple business units.

**Case Study:** How change enablement accelerates technology adoption.

## How I Work

I set strategy and creative direction first—tools execute inside that frame, never in place of it. Faster drafting and iteration buy more time for the judgment calls that actually shape outcomes. Everything I ship is reviewed and owned; accuracy, tone, and instructional integrity are mine to answer for.

## Technology

- **Framework:** React 18 (via Babel transpiler)
- **CSS:** Design system with token-based theming
- **Deployment:** Static HTML + JSX (no build step)
- **Assets:** SVG, PNG, MP4

## Getting Started

### View Locally
```bash
git clone https://github.com/jonzamarripa/jonathan-zamarripa-portfolio.git
cd jonathan-zamarripa-portfolio
open index.html
```

Or run a local server:
```bash
python -m http.server 8000

```
